# 월드컵 10판 대진 생성

- 관련 이슈: [#116](https://github.com/sugkamoney/geupjido-backend/issues/116), [투표 정책 #109](https://github.com/sugkamoney/geupjido-backend/issues/109)
- 카드 표시값: [월드컵 카드 정보 계약](worldcup-card-api-contract.md)
- 게임 시작·투표 선택 API: [#119·#122](worldcup-game-api.md)

## 입력과 결과

`MatchGenerationService`는 배너 진입 또는 선택한 권역 ID를 받아, 기준 권역과 단지 대진 10개를 반환한다. 배너 진입은 서울 60%, 경기·인천 40%를 먼저 추첨한 다음 해당 그룹의 권역을 동일 확률로 고른다. 배너 후보는 활성 단지가 4개 이상인 권역이다. 권역 상세 진입은 활성 단지가 1개 이상이면 시작할 수 있다.

후보 조회는 `MatchCandidateRepository`가 담당한다. 활성 단지의 식별자, 권역, 시·구, 사용승인일, 세대수와 대표 매매 거래의 가격·면적·계약일을 조회한다. 게임 생성은 읽기 전용 반복 읽기 트랜잭션 안에서 수행해, 후보 수와 카드 값이 같은 DB 스냅샷에 속하도록 한다. DB나 엔티티를 수정하지 않는다.

게임의 각 판은 `CROSS_ZONE` 또는 `WITHIN_ZONE`이며, 두 단지 카드에는 [카드 계약](worldcup-card-api-contract.md)의 표시값이 들어간다. 대진 생성 후의 REST 엔드포인트, 투표 선택 저장과 일일 한도는 [월드컵 게임 API](worldcup-game-api.md)에서 다룬다.

## 대진 구성

1. 기준 권역의 활성 단지로 같은 권역 대진을 최대 4판 만든다. 단지가 적어 4개의 서로 다른 단지 쌍을 만들 수 없다면 가능한 만큼만 만든다.
2. 나머지를 기준 권역과 다른 권역의 단지 비교로 채워 총 10판을 만든다. 상대 권역은 공개 급지 차이 ±0.2 이내에서 찾는다. 인접 관계나 거리 상한은 필수 조건이 아니다.
3. 상대 권역을 가능한 경우 최소 3곳 사용하고, 다른 권역 비교 6판에서는 상대 권역당 우선 최대 2판을 배정한다. 후보가 부족하면 이 분산 제한을 먼저 완화한다.
4. ±0.2 범위의 서로 다른 단지 쌍만으로 10판이 불가능하면 ±0.3까지 한 번 넓힌다. 그래도 부족하면 게임을 시작하지 않는다.
5. 한 게임에서 동일한 단지 쌍은 다시 사용하지 않는다. 개별 단지는 다른 상대와 재등장할 수 있지만, 이미 많이 등장한 단지의 선택을 뒤로 미룬다. 판의 순서와 카드 좌우도 섞는다.

## 상대 권역 추첨 확률

급지 차이가 작고 권역 중심 사이 거리가 가까울수록 높은 확률을 준다. 현재 초기 가중치는 다음과 같다.

```text
가중치 = 1 / (1 + 5 × 급지 차이) / (1 + 중심 간 거리(km) / 10)
```

거리는 SRID 4326의 권역 중심 경도·위도에 Haversine 공식을 적용한 km 값이다. 가중치는 항상 양수이므로 멀리 있는 권역도 선택될 수 있다. 예를 들어 같은 급지라면 중심 간 거리가 5km인 권역은 20km인 권역보다 약 2배 높은 가중치를 받는다. 이 수치는 사용자 정책인 `급지 우선·가까움 약간 우대`를 구현한 초기값이며, 실제 생성 대진의 분포를 보고 조정할 수 있다.

## 검증과 운영상 주의

2026-11-02 로컬 PostgreSQL·PostGIS에는 활성 권역 274개와 활성 단지 3,522개가 있었다. 모든 활성 권역이 급지 ±0.2 안에서 다른 권역 비교 6판을 만들 수 있었다. 활성 단지가 1~3개인 권역은 27개로, 이들에는 같은 권역 비교 부족분을 다른 권역 비교로 채우는 규칙이 적용된다. 이 수치는 로컬 데이터 스냅샷이며 운영 데이터의 보장은 아니다.

대진 생성 결과는 게임 시작 API가 DB에 스냅샷으로 저장하고, 투표 선택은 각 판별로 별도 저장한다. 재진입과 선택 진행 방식은 [월드컵 게임 API](worldcup-game-api.md)를 따른다. 배너의 60:40 비율은 기준 권역 추첨 확률이며, 대진 10판 전체의 단지 지역 비율을 고정하지 않는다.
