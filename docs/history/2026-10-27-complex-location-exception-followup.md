# 단지 위치 예외 후속 검토 (#91)

## 이번 검토의 결론

- #91의 마장동 권역·단지 배정은 별도 [마장동 기록](2026-10-27-majang-zone.md)에 남겼다. #90에서 남긴 다른 위치 예외도 #91에서 추적하되, 검증되지 않은 좌표와 권역은 채우지 않는다.
- 부산 단지 `A10027875`는 수도권 일괄 적재에서 새어 들어온 건이 아니다. `ComplexBasicInfoImportServiceE2ETest`가 이 ID를 실제 API로 조회해 로컬 DB에 저장했고, 테스트 종료 뒤 삭제하지 않았다. #87 초기 적재 기록에서도 이 행이 254개 법정동 수집 전부터 존재한다고 확인된다. `RUN_COMPLEX_SAVE_E2E=true`일 때만 실행되는 테스트에 트랜잭션 롤백을 적용했다.
- 로컬 DB에서 `A10027875`는 부산 사하구 괴정동 코드 `2638010100`, 마곡·마장 등 대상 권역 배정 없음, 연결 거래 0건임을 확인했다. `scripts/complex/remove_local_e2e_fixture.sql`의 주소·코드·참조 검사를 통과한 뒤 로컬 행 1건을 삭제했다. 운영 DB 적재 이력은 이 결과로 판단하지 않는다.
- 마곡 7건은 사용자가 지정한 `gangseo-magok`에 배정된 상태다. 모두 원본 법정동 코드가 방화동 `1150010900`이고, 배정 권역 다각형 안에 있는 SRID 4326 좌표다. VWorld의 **현재 연속지적도**에서 원본 방화동 지번 PNU 7개는 모두 `NOT_FOUND`였고 각 저장 좌표의 필지 역조회는 마곡동 PNU를 반환했다. 현재 경계와 현재 필지는 서로 일치한다. K-apt·네이버의 방화동 표기가 남은 역사적 이유는 별도 확인이 필요하다. 승인된 **단지별 예외 7건**으로 계속 집계한다.
- 지번 후보 12건 모두 로컬 DB에서 좌표·권역을 확정했다. 11건은 원본 지번의 VWorld 필지 안을, 나머지 이수푸르지오더프레티움 1건은 현행 도로명주소와 사당동 1161 필지를 각각 확인했다. 도로명주소 자치구 오기 2건도 서울시 공개 단지 정보로 확인해 정정했다.

## 마곡 7건의 현재 필지 대조

VWorld 2D 데이터 `LP_PA_CBND_BUBUN`에서 원본 방화동 지번 PNU를 직접 조회하고, 각 단지의 저장 좌표를 `geomFilter=POINT(x y)`로 역조회했다. 직접 조회 7건은 모두 `NOT_FOUND`, 좌표 역조회 7건은 모두 `OK`·마곡동 필지 1개였다. 이 결과는 **현재** 지적도에 대한 관측이며, 과거 방화동에서 마곡동으로 필지가 언제·어떤 절차로 바뀌었는지는 설명하지 않는다.

지번 좌표 후보 12건 중 **11건**은 VWorld 연속지적도 `LP_PA_CBND_BUBUN`에서 해당 법정동 코드·지번의 PNU 필지를 조회했고, 네이버 지번 재조회 점이 그 필지 안에 있음을 PostGIS `ST_Covers`로 확인했다. 기존 저장 점은 좌표가 없던 1건을 제외하고 모두 해당 필지 밖이었다. 후보 점이 법정동 코드와 일치하는 권역 하나에만 들어가는 것도 확인해, 이 11건의 좌표·권역을 조건부 SQL로 보정했다. 나머지 사당동 단지는 아래 별도 근거로 처리했다.

원본 지번을 보조 확인한 [K-apt 단지 공개 목록](https://www.k-apt.go.kr/cmmn/introMmentPop.do?bjdCode=11&searchOccuDate=202609&upYn=Y)에는 사당동 42, 길음동 1287, 상도동 363, 한강로2가 419가 기재돼 있다. [과거 K-apt 목록](https://www.k-apt.go.kr/cmmn/introMmentPop.do?bjdCode=11&searchOccuDate=201611&upYn=Y)에는 하월곡동 224가 기재돼 있다. K-apt 공개 목록과 기본정보 API는 같은 원천 계열이라, 11건 배정에는 별도 VWorld 필지 경계와 좌표 검증을 더했다.

필지 검증은 지번의 법정동 코드 10자리, 일반토지 구분 `1`, 본번 4자리, 부번 4자리로 19자리 PNU를 구성해 VWorld 2D 데이터 `LP_PA_CBND_BUBUN`을 조회했다. 11건은 PNU가 정확히 1개 필지를 반환했고 후보 점에 대해 `ST_Covers=true`, 기존 점에 대해 `ST_Covers=false`였다(기존 좌표 없는 1건은 제외). 11개 후보 점은 각각 대상 권역 하나 안에 있었다. 원본 도로명·지번주소는 변경하지 않고 `scripts/complex/apply_parcel_verified_locations.sql`로 좌표·권역만 반영했다. 재실행에서는 이미 배정된 11건으로 확인되고 추가 변경은 없었다.

`A10024245`는 K-apt 기본정보에 사당동 42로 표기되지만, VWorld의 해당 PNU `1159010700100420000`은 `NOT_FOUND`였다. 네이버의 `사당동 42` 재조회 점 `(126.9803695, 37.4918416)`을 VWorld에서 역조회하면 **사당동 1161-4**로 나오므로 이 점은 단지 위치로 채택하지 않았다.

[서울시 공동주택 통합정보마당의 동일 단지 ID](https://openapt.seoul.go.kr/openApt/index.do?aptCode=A10024245&tr_code=m_sweb)는 현행 도로명주소를 `동작대로39길 39`로 표기한다. 저장된 도로명주소와 일치한다. 네이버에서 이 도로명주소와 `사당동 1161`을 각각 조회하면 같은 단지명과 지번 1161을 반환한다. VWorld의 현재 PNU `1159010700111610000`은 사당동 1161 필지 1개를 반환했다. 기존 도로명주소 지오코딩 점 `(126.9804639, 37.4930732)`은 해당 필지 밖이자 사당 권역에서 약 18m 밖이지만, 사당동 1161 지번 재조회 점 `(126.9802205, 37.4924140)`은 **1161 필지 안**과 `dongjak-sadang` 권역 안에 있다. 필지와 권역은 서로 교차한다. 이에 `correct_sadang_complex_location.sql`로 지번을 사당동 1161로 정정하고 후보 좌표·권역을 반영했다. SQL 재실행은 추가 변경 없이 종료됐다. K-apt의 `42`가 남은 경위와 과거 필지 이력은 확인되지 않았다.

`A13613201`과 `A15183001`의 기존 DB 도로명주소 자치구는 각각 동대문구·관악구였다. 네이버 지번 재조회는 같은 도로·건물번호에 성북구·동작구를 반환했고, 서울시 공동주택 통합정보마당에서도 [하월곡샹그레빌의 성북구 회기로5길 100](https://openapt.seoul.go.kr/openApt/index.do?aptCode=A13613201), [해태보라매타워의 동작구 보라매로3길 29](https://openapt.seoul.go.kr/openApt/index.do?aptCode=A15183001)를 확인했다. `correct_reviewed_road_districts.sql`로 도로명주소의 자치구만 정정했다. 지번·좌표·권역은 이 단계에서 바꾸지 않았고 SQL 재실행은 추가 변경 없이 종료됐다.

## 재현 가능한 로컬 상태

`scripts/complex/audit_location_exceptions.sql`을 로컬 PostGIS에서 실행했다. 전체 단지 **4,315건 중 좌표 4,315건, 권역 배정 4,315건**이다. 보류했던 12건은 모두 권역이 있고 사당동 단지의 SRID와 공간 포함도 확인했다. 마곡 승인 예외 7건은 모두 해당 권역 다각형 안에 있고 법정동 코드 불일치는 그대로 표시된다. 부산 E2E 행은 0건이다.

남은 출처 추적은 마곡 7건의 과거 필지 이력과 K-apt 원천 표기 이유, 사당동 단지의 K-apt `42` 표기 경위다. 현재 주소·필지·공간 판정의 로컬 적재는 완료했지만, 이 과거 이력은 확인된 사실로 단정하지 않는다.
