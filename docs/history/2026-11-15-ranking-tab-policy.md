# 랭킹 탭의 권역 순위 기준

관련 이슈: [#178](https://github.com/sugkamoney/geupjido-backend/issues/178)

## 결정

랭킹 탭은 현재 서비스의 활성 권역을 처음부터 보여준다. 투표 급지가 발행되기 전에는 `initial_tier`, 발행된 뒤에는 `zone.tier`를 현재 급지로 사용한다. 각 행의 `rankingBasis`가 `INITIAL` 또는 `VOTE`인지 함께 전달한다. 따라서 탭 머리의 기준을 모든 권역이 이미 투표로 평가됐다는 뜻의 `민심 급지`로만 설명하지 않고 `현재 급지`와 행별 기준을 사용한다. 권역 안 단지 목록은 별도 기존 정책을 따른다. `INITIAL` 권역에서는 ㎡당 대표 거래 가격, `VOTE` 권역에서는 투표 점수 순이다.

순위 범위는 전체 수도권, 서울, 경기·인천 세 가지다. 각 범위의 **모든 순위 대상 권역**에 먼저 순위를 부여한 뒤 급지·상태 탭과 상승·하락 정렬을 적용한다. 예를 들어 서울 7위 권역이 2급지 탭에 나타나도 2급지 안에서 다시 1위로 매기지 않는다. 지역 필터를 바꾸면 순위와 분모가 해당 지역 범위의 값으로 바뀐다.

현재 급지가 낮을수록 앞선다. 표시 급지가 같을 때는 비교 점수가 높은 순, 발행된 권역 유효표가 많은 순, 이름과 ID 순이다. `VOTE`의 비교 점수는 `zone.score`다. `INITIAL`에는 저장된 민심 점수가 없으므로 기존 투표 계산의 출발값인 `100 - 10 × initial_tier`를 비교 점수로 사용한다. 모든 동점은 결정적으로 풀고 권역 순위에는 공동 순위를 두지 않는다. 초기 급지가 없는 권역은 현재 급지를 계산할 수 없으므로 순위를 비우고 `모으는 중`에만 포함한다.

1~5급지 탭은 **현재 급지의 정수 구간**(1.0~1.9 등)으로 분류한다. `모으는 중`은 `rankingBasis=INITIAL`인 권역을 모은 별도 상태 필터다. 초기 급지 2.4인 권역은 `2급지`와 `모으는 중`에 모두 나타난다. 따라서 급지 탭 다섯 개의 개수는 급지가 있는 순위 대상 수와 일치하지만, `모으는 중`까지 더한 값은 전체 권역 수와 비교하지 않는다. 개수는 선택한 지역 범위에 맞게 계산한다.

## 상승·하락

직전 **성공한** 발행에서 공개된 현재 급지와 이번 성공 발행의 현재 급지 숫자를 비교한다. 예를 들어 `2.8 → 2.4`는 `0.4 상승`, `1.9 → 2.2`는 `0.3 하락`이다. 처음 `VOTE`로 전환한 권역은 직전 초기 급지를 기준으로 비교한다. 표시 급지가 같다면 원점수나 순위가 달라져도 상승·하락 목록에 넣지 않는다. 상승·하락 목록은 변동 폭이 큰 순, 같은 폭이면 이번 지역 범위 순위 순으로 정렬한다. 발행 전에는 직전 발행값이 없으므로 변동을 표시하지 않는다. 예약 실행이 누락되거나 실패했을 때는 시계상 정확히 3시간 전이 아니라 마지막으로 성공해 공개된 결과와 비교한다.

발행 트랜잭션에서 이전 현재 급지와 이전 완료 시각을 보존한 뒤 새 급지·순위·표 수·완료 시각을 함께 공개한다. 중간에 실패하면 이전 발행 결과와 비교값도 함께 롤백돼야 한다.

## 모으는 중과 테스트

투표 기반 급지 전환 조건은 권역 유효표 50표, 서로 다른 익명 방문자 10명, 권역 간 유효표 20표를 모두 충족하는 것이다. 응답에는 발행된 세 수치와 `INITIAL`/`VOTE` 상태를 담는다. `N/80표`처럼 표 한 종류만으로 전환 조건을 설명하지 않는다. 세 조건을 채워도 다음 발행 전까지는 `INITIAL`이다.

첫 발행 전에도 초기 급지로 랭킹을 보여주며, 상승·하락 목록은 비어 있다. 공유 개발 DB에 가상 표를 쌓지 않는다. [가상 방문자 검증](../../scripts/test/worldcup-virtual-voters-smoke.md)을 로컬 격리 DB에서 실행해 첫 민심 전환과 랭킹 응답을 확인한다.

## 검토한 대안과 영향

투표 급지가 나온 권역만 순위를 매기면 초기에는 랭킹 탭이 거의 비어 있게 된다. 초기 급지를 임시로 사용하는 방식은 전체 권역을 바로 보여줄 수 있지만, 같은 목록에 초기와 투표 기준이 섞인다. 행별 기준을 명시해 이 차이를 드러낸다. 지역 필터를 걸어도 전체 수도권 순위 숫자를 유지하는 방식은 사용자가 요청한 서울과 경기·인천의 독립 순위를 제공하지 못한다.

기존 지도 API의 `initialRank`와 `voteRank`는 각각 초기 급지가 있는 전체 권역, 투표 급지가 발행된 권역끼리 계산한다. 새 랭킹 탭의 **현재 급지 순위**는 두 기준을 함께 사용하는 별도 값이므로, 기존 필드에 다른 의미를 덮어쓰지 않는다.
