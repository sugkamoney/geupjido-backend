# 공동주택 단지 초기 적재 재개 결과 (2026-10-27)

## 실행과 확인

- 전날 기본정보 API의 일일 한도 오류 `22` 이후 같은 매니페스트로 로컬 적재를 재개했다. 예약된 Orca 작업은 완료 신호가 없어 감시 시간 초과로 표시됐고, 매니페스트·DB의 진전은 없었다. 해당 터미널 작업을 중단하고 단일 적재 프로세스로 직접 실행했다.
- 첫 재개에서 법정동 두 곳이 완료되고 신규 단지 67건이 저장됐다. 이후 목록 API 오류 코드 `04`가 연속됐다. 간격을 둔 재시도에서 일부 정상 응답이 돌아와 적재가 더 진행됐지만, 목록 실패와 기본정보 부분 실패가 다시 발생했다.
- 기본정보 API의 실패 단지 한 건을 별도로 조회했을 때 HTTP 200 본문의 오류 코드 `04`가 확인됐다. 이는 그 시점에 두 API 모두 `04`를 반환했다는 근거다. 매니페스트의 `API 기타 오류` 전체가 모두 같은 원인이라고 확정할 수는 없다. 오늘 직접 확인한 응답에서 한도 오류 `22`는 관측되지 않았다.
- 기본정보 전체 실패가 끼면 기존의 목록 연속 실패 기준이 초기화돼 호출이 길어질 수 있었다. `import_complexes.py`에 목록 실패 또는 해당 법정동의 기본정보 항목이 모두 실패하고 신규·기존 단지가 0건인 상태가 연속 3곳이면 중단하는 기준을 추가했다. 이 기준을 포함한 Python 테스트 23개가 통과했다. 마지막 짧은 재개에서는 목록 `04` 세 곳 연속으로 중단됐다.

## 오전 중간 상태

- 매니페스트 최신 상태는 `SUCCESS` 157곳, `EMPTY` 16곳, `LIST_FAILED` 34곳, `PARTIAL` 26곳이다. 아직 조회하지 않은 법정동은 21곳이다. 성공·빈 목록으로 완료 판정된 곳은 **173/254곳**, 남은 곳은 **81곳**이다.
- `SOURCE_GAP`으로 전환된 법정동은 아직 0곳이다. 필수 원본 값이 비어 있는 단지 `A40010008`은 저장하지 않았으며 원본 결측 여부를 최종 상태에서 다시 확인해야 한다.
- 로컬 DB에는 단지 **2,712건**, 법정동 **167곳**의 행이 있다. 300세대 이상 단지는 **1,506건**이다. 이름·지번주소·법정동 코드·세대수의 기본 검증에서 이상은 0건이다. 기존 매핑 밖 단지 1건도 전체 DB 건수에 포함된다.
- 이 시점의 `./gradlew clean build`가 성공했다. 이후 같은 매니페스트로 남은 곳을 재시도했다.

## 최종 검증

- 단일 프로세스 재개 도구로 나머지를 처리했다. 매니페스트 최신 상태는 `SUCCESS` 235곳, `EMPTY` 17곳, `SOURCE_GAP` 2곳으로 **254/254곳**이다. 미조회, 목록 실패, 부분 실패 상태는 0곳이다.
- `SOURCE_GAP` 두 법정동의 단지 세 건은 기본정보 API가 정상 응답하더라도 필수 항목인 세대수가 비어 있어 저장하지 않았다. `1168010300`의 `A40010008`, `1153010800`의 `A10019934`·`A10020277`이다. 결측 단지 목록은 `data/complex/known-source-gaps.json`에 기록했다.
- 로컬 `complex` 테이블은 **4,307건**, 법정동 **238곳**, 300세대 이상 **2,442건**이다. 이름·지번주소·법정동 코드·세대수 기본 검증의 이상은 0건이고 결측 단지 세 건은 DB에 없다.
- 로컬 권역 데이터가 최신 매핑보다 오래되어 포일동 `4143010900`이 `uiwang-naeson` 권역에서 빠져 있었다. 기존 지역 적재 진입점을 최신 매핑과 행정경계 GeoJSON으로 재실행해 지역 3개, 시군구 40개, 권역 162개를 현재 매핑과 일치시켰다. 해당 권역 이름은 `포일/내손`, 동 코드는 `4143010700, 4143010900`이다. 권역 geometry의 타입·SRID 4326·유효성 검사에서 이상은 0건이다.
- 현재 권역 매핑 밖의 단지는 기존 데이터 한 건(법정동 `2638010100`)뿐이다. 이번에 처리한 254곳에 속하지 않는다.
- Python 테스트 23개와 `./gradlew clean build`가 통과했다. 이는 로컬 초기 적재 결과이며 운영 DB 적재나 월간 예약 실행 결과를 뜻하지 않는다.

## 변경사항 검토 후 보완

- 기본정보 API의 오류 코드 `04`뿐 아니라 연결·응답 중 발생한 `RestClientException`도 제한된 백오프로 재시도한다. 호출 한도 코드 `22`와 그 밖의 결과 코드는 즉시 재호출하지 않는다. 일시적인 연결 오류 뒤 성공하는 테스트를 추가했다.
- 목록·기본정보 API의 외부 오류 문구를 예외 메시지에서 제거했다. 결과 코드는 숫자 두 자리인 경우에만 보관해 로그에 임의의 외부 응답 값이 들어가지 않도록 했다. 관련 클라이언트 테스트를 보강했다.
- 보완 후 `./gradlew clean build`가 다시 통과했다. 로컬 단지 적재 건수와 원본 결측 분류는 이 코드 검토에서 변경하지 않았다.

## 후속 작업

원본 세대수가 보완되면 결측 단지 세 건을 다시 확인한다. 월간 배치의 설정·호출·기본 비활성 동작은 테스트로 확인했다. 실제 예약 시각에 운영 서버에서 실행되는지와 운영 DB 적재는 서버·DB를 마련한 뒤 배포 단계에서 검증한다. 로컬 254곳 초기 적재를 위한 Orca 재개 자동화는 목적을 달성해 제거했다. 이슈 #87의 GitHub Actions CI 결과는 브랜치를 푸시한 뒤 확인한다.
