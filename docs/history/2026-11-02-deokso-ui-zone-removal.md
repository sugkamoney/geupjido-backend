# 덕소·우이 독립 권역 폐지

2026-11-02 사용자 결정으로 투표 후보가 없고 접경 권역도 등록되지 않은 덕소 `gg-41360-099`와 우이 `gangbuk-ui`를 독립 권역에서 제외했다. 우이동 법정동 코드 `1130510400`과 경계는 기존 수유·번동 `gangbuk-suyu`에 포함한다. 수유·번동 초기 급지 4.5는 유지한다. 덕소 결정표 행은 후속 경기 권역 ID 번호가 달라지지 않도록 이력용으로 남기고 매핑과 기준표에서는 제외한다.

로컬 DB에서 삭제 전 덕소에 연결된 단지·매매·분양권 거래가 모두 0건임을 확인했다. 우이에는 활성 후보가 없는 단지 2개(우이대우 260세대, 우이동성원아파트 262세대)와 연결된 매매 거래 47건이 있었다. `scripts/location/remove_deokso_ui_zones.sql`을 롤백 실행으로 검증한 뒤 적용해 단지 2개와 거래 47건을 수유·번동으로 옮기고, 두 독립 권역을 삭제했다. 기존 우이동 경계를 수유·번동 경계에 합쳤고 강북구·남양주시 공간 도형과 수유·번동 자동 접경 관계를 다시 계산했다. 운영 DB는 변경하지 않았다.

적용 후 로컬 권역은 서울 149개, 경기 130개, 인천 3개로 총 282개다. 후보 0개 권역은 8곳이며 모두 활성 후보가 있는 접경 권역을 가진다. 재적재 시에도 동일한 결과가 나오도록 서울·경기 매핑 컴파일러와 경계 적용 스크립트의 예상 권역 수를 갱신했다. 전체 경계 재적재 경로는 Git에서 제외된 원본 GeoJSON이 없어 이번에 실행하지 못했다.
