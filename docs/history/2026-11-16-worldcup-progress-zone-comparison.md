# 일반 월드컵 진행 현황과 권역 단지 비교 분리

관련 이슈: [#193](https://github.com/sugkamoney/geupjido-backend/issues/193)

## 결정

일반 월드컵은 기존 10판 대진 규칙인 권역 안 4판·다른 권역 6판을 유지한다. 한국 시간 하루에 최대 6게임을 시작할 수 있고, 오늘 확정한 투표·건너뛰기 판을 합해 최대 60판의 진행 현황을 표시한다. 30판과 60판은 표시 기준이며 개인 선택 리포트는 이번 범위에 포함하지 않는다. 오늘의 진행 수는 `GET /api/v1/worldcup/progress`에서 조회한다.

권역에서 시작하는 단지 비교는 선택한 권역의 활성 단지만으로 서로 다른 쌍 10개를 만든다. 최소 5개 단지가 필요하다. 이 비교는 일반 월드컵의 하루 6게임·60판에 포함되지 않는다. 일반 월드컵과 권역 단지 비교에는 서로 다른 게임 조회·투표·건너뛰기 경로를 사용한다. 권역별 마지막 게임은 날짜가 바뀌어도 이어갈 수 있지만, 일반 월드컵은 해당 한국 날짜에 시작한 게임만 이어간다.

## 이유와 영향

기존 권역 시작 API는 일반 월드컵과 같은 최근 게임 슬롯을 사용했다. 이 상태에서는 권역에서 시작해도 다른 권역 대진이 섞이고, 일반 월드컵과 권역 비교가 서로의 이어하기를 가로챌 수 있었다. 저장된 게임에 `mode`를 부여하고 기존 행은 일반 월드컵으로 분류해 두 흐름을 구분한다. 권역 비교는 권역 간 급지 범위를 쓰지 않으므로 `tier_range_used`를 비울 수 있게 했다.

기존 클라이언트가 권역 시작 뒤 일반 월드컵의 `/games/current` 경로로 이어하기·투표를 호출했다면, 권역 전용 `/zones/{zoneId}/games/current` 경로로 변경해야 한다. 시작 응답의 `Location`도 이 전용 경로를 가리킨다. 공통 게임 응답 형식과 선택 비율 계산, 유효표 집계 기준은 유지한다. 권역 안에서 선택한 표는 권역 내 단지 평가에 쓰이지만 권역 간 급지 표가 되지는 않는다.

## 검증 기준

- 일반 월드컵과 권역 비교를 같은 쿠키로 시작해도 각 흐름의 대진과 진행 판이 따로 유지된다.
- 권역 비교의 모든 대진은 선택 권역 안의 서로 다른 단지 쌍이며 10판이다.
- 오늘의 진행 현황은 일반 월드컵의 투표·건너뛰기만 세고 30·60판 목표와 남은 판 수를 반환한다.
- 한국 시간 날짜 경계에서 일반 월드컵 진행 수와 이어하기 범위가 새 날짜로 바뀐다.
- 기존 게임은 마이그레이션 뒤 일반 월드컵으로 조회된다.
