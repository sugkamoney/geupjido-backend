# 인덕원 권역을 평촌에 통합

2026-11-02 사용자 결정으로 별도 인덕원 권역 `gg-41173-055`를 폐지하고, 평촌 `gg-41173-054`에 관양동 중 인덕원 행정동 경계 안의 부분을 포함했다. 통합 평촌의 급지는 기존 평촌 3.5를 따른다. 관양동의 나머지 부분은 관양 `gg-41173-130`으로 유지한다.

결정표에는 기존 인덕원 행을 이력용으로 남기되, 매핑 컴파일러와 기준표 렌더러는 권역 생성 대상에서 제외한다. 재현 가능한 전체 경기 적재 경로도 일반 권역 127개와 부분 권역 4개, 최종 경기 131개를 기준으로 수정했다. 이번 로컬 DB에는 `scripts/location/merge_indeokwon_into_pyeongchon.sql`을 적용했다. 적용 전 롤백 실행으로 같은 결과를 검증했다.

로컬 DB 결과: 인덕원 단지 3개, 연결 매매 거래 400건, 분양권 거래 0건을 평촌으로 옮겼다. 인덕원 자동 접경 2건과 기존 평촌 자동 접경 2건을 제거하고 통합 경계에 맞는 양방향 자동 접경 4건을 만들었다. 통합 평촌은 등록 단지 30개, 300세대 이상 활성 후보 23개다. 기존 인덕원 권역 ID에 남은 거래는 0건이고, 평촌 경계의 유효성과 단지 점 포함을 확인했다. 운영 DB는 변경하지 않았다.

이번 통합은 단지 수집의 누락을 해결하지 않는다. 특히 매매 실거래 원본에는 좌표가 없고, 현재 거래 범위 분류기는 법정동 코드로 권역 하나를 고르므로 관양동의 미연결 거래는 평촌·관양을 공간적으로 구분할 수 없다. 연결된 거래는 단지의 권역을 따라 재배정되지만, 미연결 거래의 권역 판정은 별도 주소·필지 근거가 필요하다.
