# 월드컵 타임라인 조회와 순위 API 정리

관련 이슈: [#160](https://github.com/sugkamoney/geupjido-backend/issues/160)

데스크톱 HTML 시안은 최근 선택을 최대 20개 표시하고, 지도에서 권역을 고른 경우 `전체 / 해당 권역 대진`으로 거른다. 권역 필터는 게임의 시작 권역이 아니라 **대결의 양쪽 권역 중 하나**를 기준으로 삼았다. 한 게임 안에서도 다른 권역 대결과 같은 권역 대결이 섞이기 때문이다.

타임라인은 `worldcup_vote`의 실제 선택을 읽는다. 건너뛰기는 제외하고, 3시간 집계의 유효표 판단과는 분리한다. 대결은 게임 생성 당시의 단지명 스냅샷을 사용해 이후 단지명 변경으로 과거 선택 표시가 바뀌지 않게 한다. 권역 이름은 현재 `zone`에서 읽는다. 내부 방문자 UUID는 응답에 넣지 않고 16개 나무 이름의 하나로 표시한다. 같은 이름이 여러 방문자에게 나올 수 있으며, 자신의 쿠키가 있으면 `나`로 표시한다.

기존 `GET /api/v1/worldcup/zones/{zoneId}/ranking`은 활성 투표 후보만 반환하는 별도 조회 경로였다. 지도 권역 상세 API가 전체 서비스 단지의 순위와 표시 데이터를 제공하므로 전용 경로와 조회 코드를 제거했다. 집계 완료 시각은 지도 상태 API에서 읽는다. 이미 배포된 클라이언트가 이 경로를 호출하는 경우 새 지도 경로로 바꿔야 한다. 현재 프런트엔드 핸드오프 문서에는 기존 경로 사용처가 없었다.
